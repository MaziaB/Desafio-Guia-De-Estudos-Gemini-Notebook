# Desafio-Guia-De-Estudos-Gemini-Notebook
Esse é um miniguia de estudos para lógica de programação, um conceito indispensável para  quem deseja programar, independente da linguagem utilizada. Esse miniguia tem como objetivo reforçar o estudo em lógica de programação, nos ajudando assim a aprimorar nossos códigos e a solucionar problemas com mais facilidade.
